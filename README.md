# 星河画卷 · 4K 流动摄影墙

> Starry Canvas — A 4K live photo-wall wallpaper for Wallpaper Engine

![preview](preview.jpg)

精选摄影作品汇聚成一面缓缓流转的影像长廊，满天星辉微微闪烁，偶有流星划过夜空。

---

## ✨ 特性

- **流动照片墙** — 数百张高清摄影作品自动拼贴为缓缓流动的照片墙
- **满天星辉** — 温柔静谧的夜空氛围，400 颗星星随机闪烁
- **流星划过** — 偶尔划过的流星，增添梦幻感
- **入场特效** — 主图随机入场动画（放大漫游 / 模糊渐清 / 马赛克 / 黑白褪色 / 湖面涟漪 等）
- **4K 原生分辨率** — 适配超宽屏与多显示器
- **主题自定义** — 控制面板可一键隐藏，主题色自由定义
- **本地运行** — 全部素材本地打包，无需联网
- **内置音乐播放器** — 119 首歌曲播放列表，支持音量控制与歌词同步

## 🚀 使用方法

### 通过 Steam 创意工坊订阅

在 Wallpaper Engine 创意工坊中搜索 **"星河画卷"** 并订阅即可。

### 手动安装

1. 下载或克隆本仓库
2. 打开 Wallpaper Engine
3. 点击左下角 **"打开壁纸"** → 选择 `index.html`
4. 或者将整个文件夹放入 Wallpaper Engine 的 `projects/myprojects` 目录

---

## 🎮 操作

- 鼠标悬停显示控制面板
- 支持上一首 / 下一首 / 暂停 / 音量调节
- 点击切歌按钮切换歌曲
- 歌词随音乐同步滚动
